Parts list for Dual Core 65C02
==============================

## Integrated Circuits

* 2 x W65C02S 8-bit microprocessor
* 1 x W65C22N versatile interface adapter (VIA)
* 1 x W65C51N asynchronous communications interface adapter (ACIA)
* 1 x 62256 32K x 8 static RAM, 70ns or better access time
* 1 x 28C256 32K x 8 EEPROM, 150ns or better access time
* 1 x MAX232 RS-232 line driver
* 1 x 7555 CMOS timer
* 3 x 74HC00 quad 2-input NAND gate
* 1 x 74HC02 quad 2-input NOR gate
* 1 x 74HC08 quad 2-input AND gate
* 1 x 74HC10 triple 3-input NAND gate
* 1 x 74HC32 quad 2-input OR gate
* 1 x 74HC74 dual D flip-flop
* 1 x 74HC86 quad 2-input XOR gate
* 2 x 74HC138 1 of 8 decoder
* 1 x 74HC245 8-bit bus transceiver
* 1 x 74HC259 8-bit addressable latch
* 1 x 74HC4017 decade counter

## Resistors

* 6 x 470R resistor
* 7 x 1K resistor
* 1 x 2K2 resistor
* 1 x 5K6 resistor
* 5 x 10K resistor
* 1 x 1M resistor
* 1 x 10K trimpot

Note: All resistors should be rated for at least 5% tolerance and 1/4W.

## Capacitors

* 1 x 100uF electroltic capacitor, min 10V rating
* 4 x 1uF ceramic or monolithic capacitor
* 22 x 100nF ceramic or monolithic capacitor
* 1 x 10nF ceramic or monolithic capacitor
* 1 x 20pF ceramic capacitor

## Diodes and LED's

* 2 x 1N5819 Schottky diodes or equivalent
* 1 x 5mm LED
* 5 x 3mm LED

Note: The current-limiting resistors for the LED's are specified as 470R
which is suitable for standard 10mA to 20mA LED's.  Adjust the value of the
current limiting resistors for other LED's.

## Sockets, Recommended

* 3 x 40-pin DIP socket (2 x W65C02S, 1 x W65C22N)
* 2 x 28-pin DIP socket (1 x 62256, 1 x W65C51N)
* 1 x 28-pin ZIF socket (1 x 28C256)

## Sockets, Optional

* 1 x 8-pin DIP socket
* 9 x 14-pin DIP socket
* 5 x 16-pin DIP socket
* 1 x 20-pin DIP socket

## Connectors and Headers

* 1 x DC barrel jack
* 1 x DSUB 9-pin RS-232 connector female
* 1 x 3-pin Phoenix connector or 3-pin 5.08mm pitch screw terminals
* 1 x 3-pin 2.54mm terminal pin header
* 2 x 2-pin 2.54mm terminal pin header
* 1 x 10-pin 2.54mm terminal pin header, 5x2 configuration
* 1 x 22-pin 2.54mm terminal pin socket
* 1 x 80-pin 2.54mm terminal pin socket, 40x2 configuration
* 8 x 2-pin 2.54mm jumper (NMI1, NMI2, VIA IRQ, and 5 Aux Inputs)

## Other

* 1 x 12MHz DIP-14 crystal oscillator
* 1 x 1.8432MHz crystal
* 1 x 3-pin 2.54mm pitch slider switch for power
* 1 x 6mm momentary pushbutton for reset
* 1 x PCB
