
This directory contains a machine monitor for the Dual Core 65C02 Computer.

The name of the monitor is "Maggot MON", which is the name I used for my
replacement machine monitor projects for the Dick Smith Cat in the 1980's.
I was 15 years old!

Maggot MON has evolved over the years into a replacement for the
Apple II F8 ROM for use with homebrew 6502 computers.  Now with ANSI
colour codes over a TTY, support for lower case, improved assembler and
disassembler, and so on.

On a dual core system, the monitor runs in CPU1.
